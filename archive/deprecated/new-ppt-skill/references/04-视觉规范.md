# 04 · 视觉规范（藏紫陶土·米白暖纸）

> 本文件是 ppt-skill 的**人可读视觉真值**，`deck_spec.json` 的 `theme` 段是它的机器版，两者一一对应。
> 改风格只改这两处；工具层 `DEFAULT_THEME` 只做兜底，不覆盖这里的显式值。

---

## 一、设计语言一句话

**米白暖纸 + 藏紫主字 + 陶土点缀**：像一册线装暖纸报告——沉稳、有纸感，圆角卡片与陶土色条负责"灵动"那一下。

---

## 二、配色（全部 6 位十六进制，不带 #）

用户给定的四原色：深紫 `2C2048` / 陶土棕 `C89F6F` / 米白 `F8F2E9` / 浅灰 `A9A4B2`。
下表中带 ※ 的是同色系推导色（原因见备注），其余直接取原色。

### 2.1 角色色

| 角色 | 色值 | 用途 |
|---|---|---|
| `title` | `2C2048` 藏紫 | 页眉标题、结论栏文字、卡片标题、封面色带底 |
| `accent` | `C89F6F` 陶土棕 | kicker、kicker色条、结论栏左侧条、KPI数值（info时）、图表第2色 |
| `muted` ※ | `7C7689` 深灰紫 | 页码、脚注、卡片正文、图例（浅灰 `A9A4B2` 做小字对比度不足，加深后保证可读） |
| `page_bg` | `F8F2E9` 米白 | 页面底（整页暖纸感的来源） |
| `panel` ※ | `F1E8D5` 暖纸深一档 | 结论栏底、表格头（米白原色做面板在白页上不可见，加深一档才有"卡片浮起"感） |
| `text` | `2C2048` 藏紫 | 正文、图表数据标签、轴刻度（主文字统一藏紫） |
| `line` ※ | `D9CDB4` 浅陶土线 | 页眉分隔线、卡片边框、表格线、网格线（陶土降饱和，保证细线不抢戏） |
| `on_dark` | `F8F2E9` 米白 | 封面色带上文字 |
| `on_dark_muted` ※ | `D9C6A5` 浅陶土 | 封面副标题 |

### 2.2 语义色（全篇固定，不许同色不同义；均为藏紫/陶土系推导，保证暖纸上和谐）

| 语义 | 色值 | 含义 |
|---|---|---|
| `ok` | `6FA287` 灰绿 | 达标（低饱和，配米白不刺眼） |
| `warn` | `C98A2B` 深金 | 预警（陶土系加深，暖纸上可读） |
| `bad` | `B44A4A` 陶红 | 未达标（陶土偏红，暖纸上可读） |
| `info` | `6E6590` 灰紫 | 中性/说明（藏紫降饱和） |

### 2.3 图表调色板（顺序即语义）

```
1. 2C2048 藏紫 —— 主强调（单系列默认色、第一系列）
2. C89F6F 陶土棕 —— 对比色（第二系列）
3. 6E6590 灰紫 —— 第三系列
4. D4B78F 浅陶土 —— 第四系列
5. A9A4B2 浅灰（原色） —— 第五系列 / 次要系列
6. 5A4E7A 深灰紫 —— 第六系列 / 兜底
```

单系列柱/条统一用藏紫；`point_colors` 声明语义时按点上色（应收=info灰紫、实收=ok灰绿、未缴=bad陶红，见收缴率页）。

## 三、字体（圆滑 + 清晰）

| 角色 | 字体 | 字号 | 说明 |
|---|---|---|---|
| 标题 | 幼圆 | 21pt 加粗 | 圆润且远距离可读；缺字体时回落微软雅黑，不影响排版 |
| 正文 | 微软雅黑 | 12pt | 全篇统一，颜色藏紫 |
| kicker（阶段标签） | 幼圆 | 11pt 加粗 | 前带 3.5pt 宽陶土小色条 |
| 卡片标题 | 幼圆 | 12.5pt 加粗 | 颜色藏紫 |
| 卡片正文 | 微软雅黑 | 10.5pt | 颜色 muted |
| 脚注/口径 | 微软雅黑 | 8.5pt | 颜色 muted |
| 封面主标题 | 幼圆 | 34pt 加粗 | 米白字压藏紫色带 |
| 封面副标题 | 微软雅黑 | 15pt | `on_dark_muted` |
| 封面项目/期间 | 幼圆 | 20pt 加粗 | |
| KPI数值 | 幼圆 | 24pt 加粗 | 颜色=状态语义色 |
| KPI标签 | 微软雅黑 | 11pt | 颜色 muted |
| 图表字 | 微软雅黑 | 10.5pt | 轴刻度 -1pt，数据标签 -1.5pt |
| 行距 | — | 1.25 | 全篇统一 |

中英文混排：西文随正文字体（微软雅黑内置拉丁），不单独设 fallback，避免中西文基线错位。

## 四、版式（16:9，13.333 × 7.5 英寸）

- 边距 `margin_in` 0.62；正文区 `body_top` 1.52 → `so_what_top` 6.18（约 4.66 英寸）。
- 封面色带高 `cover_band_in` 4.3，标题块在色带内垂直居中，项目/期间压色带底沿。
- KPI 网格 3 列，卡片网格 2 列（3 张卡时按内容列数算法自动取 3 列，避免右半页留空）。
- 页码开：右上 `footnote_size+1.5` 的 muted 小字，不抢标题权重。
- 内容少的页面：**空白留在内容之外**（上半页讲完、下半页留白），不把卡片拉成空壳。

## 五、装饰（纸感 + 灵动的来源）

| 开关 | 值 | 效果 |
|---|---|---|
| `card_shape` | `rounded`，`radius` 0.2 | 全篇圆角矩形，卡片底取米白/白，边框浅陶土线 |
| `header_rule` | true | 标题下细陶土线 |
| `kicker_bar` | true | flatdoodle 风下 kicker 改为陶土小药丸（转译参考图橙色导航条），不再用色条+纯文本 |
| `so_what_style` | `panel` | 结论栏=暖纸底 + 左侧 0.07" 陶土条，文字"结论 \| …" |
| `cover_band` | true | 封面顶部藏紫色带（`title` 色）+ 米白字 |
| `chart_gap_width` | 75 | 2~3 根柱子粗细适中，不牙签 |
| `chart_gridlines` | true | 只留数值轴方向浅陶土网格线，分类轴网格线关闭；数据标签放柱外侧末端 |
| `bg_style` | `flatdoodle` | 背景涂鸦层总开关（转译 landing 参考图）；`plain`=无装饰 |
| `bg_doodles` | true | 涂鸦层明细开关（与 bg_style 联动，默认跟随） |

### 5.1 背景涂鸦层（flatdoodle 风，转译自 landing 参考图）

只取装饰语言，不搬网页结构（橙色导航条→kicker小药丸，人物/柱状图/大箭头不搬）：

| 元素 | 转译 | 配色 | 位置 |
|---|---|---|---|
| 空心圆 | 藏紫描边小圆 | `title` | 封面左上/左下、内容页右下 |
| 波浪线 | freeform 正弦波 | 封面藏紫、内容页浅灰紫 | 封面左上、内容页左下贴边 |
| 实心圆点 | 陶土小点 | `accent` | 封面左下点缀 |
| 同心靶环 | 外陶土→白→陶土环→白心（参考图右侧大靶） | `accent`+白 | 封面右上大靶、内容页右上小靶一角 |
| 上升箭头 | 参考图右下粉箭头，取浅陶土不抢戏 | `line` | 封面右下 |
| 小药丸标签 | kicker 胶囊（参考图橙条/蓝条） | 陶土底+米白字 | 页眉 kicker 位，宽按字数自适应 |

全部先画、被正文覆盖，只在留白处露出来；单个装饰失败静默跳过，不影响整页。关掉只需 `bg_doodles: false`（或 `bg_style: plain`），老主题不受影响。

## 六、可互动（已落地）

- 路线图页卡片**点击跳转**到对应章节页（点卡片底块，不点文字——放映时整卡可点）。
- 每页页脚导航：`◀ 上一页 ｜ 回目录 ｜ 下一页 ▶`，点击跳转；封面为 `开始 ▶` 跳到第二页；目录页只有上一页/下一页。
- 实现：`tool/common/deck_build_tool.py` 二遍布线（先渲染全部页，再挂 `click_action.target_slide`；路线图属前向引用，必须二遍才能挂）。主题开关 `decor.nav`（默认开）。
- 口径备注（`_footer`）自动给右侧导航让宽，不重叠。

---

## 七、校验门禁

- `pptx_check` 的 `allowed_colors` 取本规范全部色值 + 白；涂鸦层严格用主题色、无新色，校验零改动。`must_contain` 保持"一页纸结论 / 异常科目归因 / 总结行动"三必须页。
- `overflow` 为估算，允许少量 warn，但需人工确认是否真裁切。
- 基线：固定输入跑通后转 PNG 存 `assets/baseline/`，以后改样式必须 diff 这套图；同一份数据连跑两次像素级一致（除时间戳）。
