# 常用文件目录（data/）

把**经常要用的业务文件**放这里，就不用每次告诉 Agent 文件在哪。

```
data/
├── common/          ← 常用文件都放这里（默认搜索根）
│   └── .gitkeep
├── inbox/           ← 临时/待处理文件，也算常用范围
│   └── .gitkeep
└── README.md        ← 本文件
```

## 为什么要有这个目录

用户说「用上个月的销售表做个 PPT」时，Agent 不需要用户给出完整路径 ——
它会：

1. 从请求里**解析文件名线索**（"销售表"、"上个月"）
2. 在 `data/common` + `data/inbox` 里**按文件名/关键词模糊匹配**
3. 用 `data_analysis` 工具读取并抽数
4. 喂给 `ppt-skill` 生成演示文稿

## 支持的格式

| 格式 | 读取方式 |
|---|---|
| `.xlsx` / `.xlsm` | openpyxl |
| `.csv` / `.tsv` | csv（自动嗅探编码与分隔符） |
| `.json` | json |

## 覆盖搜索根

默认搜索 `data/common` 和 `data/inbox`。要换位置，设环境变量：

```powershell
$env:SKILL_COMMON_DIRS = "D:\我的表格;E:\共享\月报"
```

多个目录用 `;`（Windows）或 `:`（Linux/macOS）分隔。

## 命名建议

文件名本身就是线索，建议带上**业务名 + 期间**，越好认越准：

```
✅ 销售成交汇总_2026-09.xlsx
✅ 物业经营分析_阳光花园_2026Q3.xlsx
❌ 新建工作表 (3).xlsx
❌ 未命名1.xlsx
```

因为 Agent 是按文件名做匹配的 —— 名字里有"销售""2026-09"，
它就能在"用 9 月销售数据出个 PPT"这句话里对上号。
