**场景**：多轮业务数据分析，生成统计表、回归结果、多表 join，生产商用 Agent
**核心方案：Artifact 外置策略（强烈推荐你参考）**

1. 所有中间计算结果、DataFrame、表格，**不放入对话上下文**，保存为独立 Artifact（制品，存在 Postgres）
2. Agent 对话消息里只写引用：`[Artifact ID:tbl_001，表名：月度销售，字段：区域/月份/营收，行数1200；可调用query工具抽样查看]`
3. 上下文压缩只对**任务规划、约束、业务口径、已完成结论**做结构化摘要；**表格明细永远不走 LLM 上下文**
4. Agent 如需查看数据，调用工具去 Artifact 存储里抽样 head/tail/ 筛选，按需加载少量样本进 prompt
