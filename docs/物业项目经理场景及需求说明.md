# 物业项目经理常见场景及需求说明

> 适用对象：物业项目经理日常经营与管理工作，可作为 AI 助手 / Agent 系统的需求输入与任务模板库。
> 数据基础参考：房产客户信息、应收信息、缴费数据、欠款明细报表、房产收缴率明细表。

---

## 第一部分：常见场景及需求说明（14 个）

### 场景 1：收缴率统计与欠费分析

**场景描述**：项目经理需按周期（月/季/年）统计各楼盘、楼栋、单元的物业费收缴率，识别欠费重灾区，向公司汇报并制定催缴策略。

**核心需求**：
- 应收 / 实收 / 欠费金额自动汇总，收缴率 = 实收 ÷ 应收 × 100%
- 支持按楼盘、楼栋、户型、楼龄等多维度切片
- 与上期、去年同期对比，标注升降趋势
- 输出 Top N 欠费楼盘 / 楼栋清单

### 场景 2：账龄分析与催缴优先级排序

**场景描述**：欠费时间越长回收难度越大，需对欠费按账龄分档（30 天内、31–90 天、91–180 天、180 天以上），并据此排出催缴优先级。

**核心需求**：
- 按账龄区间自动分档统计金额与户数
- 结合欠费金额、账龄、历史缴费信用生成催缴优先级评分
- 区分"恶意欠费"与"遗忘/争议欠费"，建议差异化催缴方式

### 场景 3：催缴通知生成（催缴函 / 短信 / 微信模板）

**场景描述**：针对不同账龄档位的欠费客户，生成不同语气的催缴通知。

**核心需求**：
- 语气分级：温馨提醒（30 天内）→ 正式催缴（90 天内）→ 律师函预警（180 天以上）
- 自动填入客户姓名、房号、欠费金额、账龄、缴费渠道
- 合规底线：不得含威胁、恐吓、泄露隐私内容，不得违法

### 场景 4：客户信息档案管理

**场景描述**：业主 / 租户信息变更（过户、换手机号、出租转自住、空置房认定）频繁，需保持台账准确。

**核心需求**：
- 变更登记：按房号定位记录，更新联系方式、居住状态、关联人
- 空置房标记（通常涉及物业费减免政策）
- 敏感信息脱敏：对外输出时手机号、身份证号部分隐藏

### 场景 5：客户投诉与报修工单管理

**场景描述**：业户投诉（保洁、噪音、漏水、电梯故障等）需快速受理、派单、跟踪、闭环、回访。

**核心需求**：
- 工单结构化录入：类型、紧急程度、责任岗位、时限
- 按紧急程度自动分级（如电梯困人 = 最高级，立即响应）
- 超时预警：临期 / 逾期工单自动提醒
- 闭环率、及时率统计，沉淀高频问题知识库

### 场景 6：周期性经营报表生成

**场景描述**：项目经理需定期输出日 / 周 / 月经营报表（收缴率、工单、能耗、投诉），供公司例会使用。

**核心需求**：
- 一句话生成标准格式报表，数据来源：应收、实收、欠款明细、收缴率明细
- 报表结构固定：核心指标 → 环比变化 → 异常说明 → 下期计划
- 异常自动识别：收缴率骤降、投诉激增、能耗异常等需显著标注

### 场景 7：设备与公共区域巡检管理

**场景描述**：电梯、消防、水泵、配电等设备需按计划巡检并留痕，公共区域需日常巡查。

**核心需求**：
- 巡检计划生成（按设备类型、频次要求）
- 巡检异常上报 → 自动转工单
- 巡检完成率统计，漏检自动提醒

### 场景 8：客户满意度调查与分析

**场景描述**：定期开展满意度调查（线上问卷 / 电话回访），分析弱项并制定整改计划。

**核心需求**：
- 问卷设计（保洁、秩序、工程、客服四大条线 + NPS）
- 结果统计：各条线得分、与上期对比、负面评价归类
- 输出弱项整改建议及责任条线

### 场景 9：装修管理

**场景描述**：业主装修需申请备案、缴装修押金、巡查违规（拆承重墙、违规改动管线）。

**核心需求**：
- 装修申请登记与审批状态跟踪
- 违规风险清单与整改通知生成
- 押金退还流程提示（验收通过后）

### 场景 10：车位管理

**场景描述**：产权车位 / 租赁车位 / 临时车位的台账管理，车位费与物业费合并或分开催缴。

**核心需求**：
- 车位台账：业主、车位号、类型、有效期
- 租期到期预警（提前 30 天）
- 欠费车位与欠费房产的关联分析

### 场景 11：预算与成本管控

**场景描述**：年度预算编制与执行监控（人工、能耗、外包、维修物料），月中发现超支需纠偏。

**核心需求**：
- 预算执行率 = 实际支出 ÷ 预算 × 100%，按科目统计
- 超支科目预警及原因分析
- 能耗（水电气）用量环比异常识别

### 场景 12：突发事件应急响应

**场景描述**：电梯困人、消防报警、跑水、极端天气、群体性事件等突发事件处置。

**核心需求**：
- 分场景应急预案要点速查（响应时限、上报链路、关键动作）
- 事件记录与事后复盘报告生成
- 对外通报口径（业主群公告）合规撰写

### 场景 13：团队排班与考勤管理

**场景描述**：秩序、保洁、工程等岗位需排班，节假日 / 突发缺岗需快速补位。

**核心需求**：
- 按岗位编制生成周排班表
- 缺岗提醒与替补建议（就近技能匹配）
- 考勤统计与加班预警

### 场景 14：项目交接与工作总结

**场景描述**：项目经理轮岗交接、月度 / 年度述职总结。

**核心需求**：
- 交接清单生成：在管项目概况、欠费风险、未闭环工单、重点客户、遗留问题
- 述职报告结构化：经营指标完成情况、重点工作、问题反思、下期规划

## 第二部分：可复用 Prompt / 任务模板（14 个）

> 使用说明：`{{ }}` 内为待替换变量；可逐条复制给 AI 助手执行。

### 模板 1：收缴率统计

```
你是物业项目经理的数据分析助手。请基于应收信息、缴费数据和房产收缴率明细表，
统计 {{楼盘/楼栋名称}} 在 {{统计周期}} 的物业费收缴情况：
1. 应收金额、实收金额、欠费金额、收缴率（实收÷应收×100%）；
2. 与上一周期对比，标注升降及幅度；
3. 列出欠费金额 Top {{N}} 的楼栋/单元；
4. 用不超过 5 句话给出结论与建议。
结果以表格输出，金额单位统一为元，保留两位小数。
```

### 模板 2：账龄分析与催缴优先级

```
基于欠款明细报表，对 {{楼盘名称}} 的欠费客户做账龄分析：
1. 按 30 天内 / 31–90 天 / 91–180 天 / 180 天以上分档，统计各档户数与金额；
2. 对每位欠费客户按以下规则打催缴优先级分：
   账龄越长权重越高（30 天内 1 分、31–90 天 2 分、91–180 天 3 分、180 天以上 5 分）
   + 欠费金额每 {{X}} 元加 1 分 + 有历史欠费记录加 2 分；
3. 按得分从高到低输出催缴名单（房号、户主、金额、账龄、得分、建议催缴方式）。
```

## 附：使用约定

1. **数据口径**：收缴率 = 实收 ÷ 应收 × 100%；账龄自费用应缴日起算；金额一律保留两位小数。
2. **合规红线**：所有对外文本（催缴函、通知、公告）不得含威胁恐吓措辞，不得泄露客户隐私；个人信息展示一律脱敏。
3. **变量规范**：模板中 `{{ }}` 为必填变量，使用前逐项替换；未提供的变量标注"待补充"，不得臆造数据。
4. **输出规范**：统计类任务优先用表格；结论类内容控制条数与字数；日期统一 `YYYY-MM-DD`。
