# 催缴通知语气模板（三档）

> 使用时替换 `{姓氏}` `{房产}` `{期间}` `{金额}` `{限期}` 占位符；
> 数据必须来自 `arrears_analysis` 的真实返回，不得编造。

## 第一档：温馨提醒（账龄 ≤90 天，短信/微信）

**短信模板（≤70 字）**：

```
{姓氏}先生/女士您好，您的{房产}{期间}物业费{金额}元尚未缴纳，为避免产
生违约金请于{限期}前缴费。已缴请忽略。详询物业客服。
```

**微信模板（≤300 字）**：在短信基础上补充缴费渠道（前台/二维码/线上小程序）、
客服电话与营业时间；语气轻松，结尾"感谢您的支持！"

要点：
- 开头友好，不指控"恶意欠费"；
- 给出明确的缴费动作与渠道；
- "已缴请忽略"避免打扰已缴客户。

## 第二档：正式催缴（账龄 91-180 天，微信+催缴函）

**微信/书面通用模板**：

```
{姓氏}先生/女士：经核对，您名下{房产}截至{限期}累计欠缴{期间}物业费
{金额}元。我司已于前期多次提醒，现正式催缴，请您于{限期}前结清。
依据《民法典》第九百四十四条及《物业服务合同》第X条，逾期将按约定
计收违约金。如对费用有异议，请于收函后7日内联系客服核对。
```

要点：
- 陈述事实（期间、金额）+ 法律依据（民法典第944条）；
- 给异议渠道与 7 日核对期，避免"剥夺申辩"之嫌；
- 提及违约金按合同约定，不夸大金额。

## 第三档：律师函预警（账龄 >180 天，书面函 + 转法务）

**书面模板**：

```
{姓氏}先生/女士：您名下{房产}物业费欠款{金额}元（欠费期间：{期间}），
经多次催缴至今未结清。请您于{限期}前付清；逾期我司将委托律师事务所
发出律师函，并保留依法起诉、主张违约金及相关费用的权利。
```

要点：
- 措辞严肃克制，只陈述已发生的催缴事实与拟采取的法律途径；
- **不得虚构**"已起诉""已查封""已上报征信"等未发生的事实；
- 生成正式函件用 `docx_letter`（letter_type=律师函预警 或 律师函）；
- 同步建议项目经理把该户转法务跟进。

## 升级规则

账龄档由 `arrears_analysis` 返回；按档选择语气，**只升不降**：
同一户已发过正式催缴函的，不再退回温馨提醒档。
