# 指标口径、异常归因与图表选择手册

## 一、核心指标定义表（口径必须写进汇报脚注）

### 收入类

| 指标 | 计算口径 | 参照系 | 预警阈值（参考） |
|---|---|---|---|
| 预算完成率 | 本月确认收入 / 本月预算收入 | 月度预算 | < 95% 预警 |
| 权责收入 | 按权责发生制确认的应收 | 预算 / 上月 / 同期 | — |
| 实收金额 | 本月实际到账现金 | 预算 / 上月 | — |
| 公共收益 | 广告位、场地租赁、通信基站、快递柜、经营性用房租金等 | 预算 / 台账 | 未按月公示即预警 |
| 多种经营收入 | 家政、代收代缴手续费、房屋租售中介、社区团购等 | 预算 / 上月 | 毛利率 < 20% 预警 |

> 口径红线：**公共收益依法属于全体业主共有**，必须在报表中单独列示、单独建账，不得计入物业公司经营利润作为业绩。

### 成本类

| 指标 | 计算口径 | 预警阈值（参考） |
|---|---|---|
| 人力成本 | 工资 + 社保公积金 + 福利 + 外包人工折算 | 占收入比 > 55% 预警 |
| 能耗成本 | 公共区域水电 + 物业自用水电（分列） | 环比波动 > 15% 需解释 |
| 外包服务费 | 保洁 / 绿化 / 秩序外包合同结算额 | 单价环比上涨 > 5% 需说明 |
| 维修维保 | 日常维修 + 设备维保 + 专项维修（分列） | 单项 > 预算 20% 触发归因 |
| 物料耗材 | 清洁用品、办公用品、工装等 | — |
| 管理费与其他 | 差旅、通讯、保险、税费、诉讼费等 | — |
| 成本率 | 总成本 / 营业收入 | 行业参考区间 75%~88% |
| 人均效能 | 人均管理面积、人均产值、人均工单量 | 环比下降 > 5% 需归因 |

### 收缴类

| 指标 | 计算口径 | 说明 |
|---|---|---|
| 当期收缴率 | 当月实收（当月账单）/ 当月应收账单 | 反映当月服务质量 |
| 累计收缴率 | 年初至今实收 / 年初至今应收 | 反映全年经营质量 |
| 陈欠回收率 | 本期回收历史欠费 / 期初陈欠总额 | 反映催收与管理能力 |
| 账龄结构 | 0–30 / 31–90 / 91–180 / 180+ 天 | 账龄越长，回收概率断崖式下降 |
| 欠费户数占比 | 欠费户数 / 总户数 | 区分"少数大户欠费"还是"大面积欠费" |

**账龄与回收概率经验值**（用于说服领导投入催收资源）：

| 账龄 | 回收概率（经验参考） |
|---|---|
| 0–30 天 | 85%~95% |
| 31–90 天 | 60%~75% |
| 91–180 天 | 30%~45% |
| 180 天以上 | 10%~20% |

### 效能类

| 指标 | 计算口径 |
|---|---|
| 人均管理面积 | 在管建筑面积 ÷（自有员工 + 外包折算人数） |
| 人均产值 | 营业收入 ÷ 项目总人数 |
| 人工成本率 | 人力成本 ÷ 营业收入 |
| 人均工单量 | 完成工单数 ÷ 工程人员数 |
| 报修及时率 | 按时完成的报修单 ÷ 报修单总量 |
| 投诉闭环率 | 已闭环投诉 ÷ 投诉总量 |

## 二、异常科目归因：三层穿透法

### 第一层 · 量化偏差（先分清是"量差价差口径差"）

```
偏差额 = 实际 - 预算（或 -上月 / -去年同期）
偏差率 = 偏差额 ÷ 基准值
```

拆解公式（以人力成本为例）：

```
人力成本偏差 = 人数偏差 × 预算人均工资   （量差）
             + 预算人数 × 人均工资偏差   （价差）
             + 口径/一次性因素           （口径差）
```

| 差异类型 | 典型情形 | 处置方向 |
|---|---|---|
| 量差 | 加班工时增加、补岗、临时用工 | 排班优化、定编复核 |
| 价差 | 最低工资上调、社保基数调整、外包单价涨 | 预算重估、合同谈判、服务标准重设 |
| 口径差 | 一次性维修、跨月费用、计提方式变化 | 澄清口径，不进入考核，但需说明 |

### 第二层 · 驱动因素（拆到可解释的具体事件）

必须写到"能追溯到某一天、某个人、某张单"的粒度：

- ❌ "能耗上升" → ✅ "能耗超支 2.1 万元，其中地库照明改造延后导致 1 月全月沿用旧灯具（超 1.2 万元），另有 3 台电梯年检前试运行时间延长（超 0.9 万元）"
- ❌ "维修费超支" → ✅ "维修费超支 3.4 万元，其中 5# 楼污水管爆管应急抢修 2.6 万元（不可控），另有 0.8 万元为保洁工具重复采购（可控）"

### 第三层 · 责任归属与可控性

| 可控性 | 判定标准 | 处置 |
|---|---|---|
| 完全可控 | 项目自身管理行为导致 | 纳入项目考核，本月即纠偏 |
| 部分可控 | 需跨部门协调或需提前规划 | 定责任人 + 时限，跟踪到下月 |
| 不可控 | 政策调整、突发故障、极端天气、司法程序 | 申请预算调整，做风险备案，不进入处罚 |

## 三、异常科目归因表（汇报核心页模板）

| 科目 | 偏差额 | 偏差率 | 主因（可追溯事件） | 可控性 | 责任部门 | 纠偏动作 | 时限 |
|---|---|---|---|---|---|---|---|
| 人力成本 | +8.2 万 | +12.5% | 秩序岗 2 人离职，补岗空窗 12 天产生加班费 | 部分可控 | 秩序部 | 建立岗位 AB 角与应急替班池 | 下月 15 日前 |
| 公共能耗 | +2.1 万 | +18.3% | 地库照明改造延后 + 电梯年检试运行 | 部分可控 | 工程部 | 加快 LED 改造招标 | 下月底 |
| 绿化外包 | +1.4 万 | +9.6% | 合同单价上调 5% + 补种乔木 6 株 | 部分可控 | 环境部 | 修订养护标准，按次核量结算 | 下月 10 日前 |
| 维修维保 | +3.4 万 | +26.0% | 5# 楼污水管爆管应急抢修 | 不可控 | 工程部 | 申请专项预算调整 + 老旧管网排查 | 本月底 |
| 多种经营收入 | −1.8 万 | −22.5% | 家政服务团队流失，接单能力下降 | 完全可控 | 客服部 | 重启合作方招募与分成方案 | 下月底 |

**使用纪律**：
- 偏差率 > 10% 或偏差额进 TOP5 的科目必须进此表。
- "责任部门"只能填一个主责部门（其他为配合），避免责任分散。
- "时限"必须具体到日期，不能写"尽快"。

## 四、图表选择对照表

| 要表达的内容 | 首选图表 | 禁忌 |
|---|---|---|
| 收入结构占比 | 环形图 / 堆积柱状图 | 饼图切片超过 6 个 |
| 预算 vs 实际对比 | 簇状柱状图 | 折线图（失去绝对值感） |
| 成本科目排序 | 横向条形图（降序） | 无序排列 |
| 偏差归因（预算→逐项累加→实际） | 瀑布图 | 普通柱状图（看不出归因过程） |
| 趋势（3~12 个月） | 折线图 + 目标参考线 | 只有两三个点时用折线 |
| 收缴率与账龄 | 漏斗图 + 分档堆积柱 | 单一百分比数字 |
| 人均效能对比 | 组合图（柱=产值，线=人工成本率） | 双柱混淆主次 |
| 异常科目责任分布 | 归因表（表格） | 图表（表格信息密度更高） |

**图表纪律**：
1. 每张图必须有结论型标题。
2. 数据标签直接标在图上，避免听众去读坐标轴。
3. 单位统一（万元 / 元 / %），一张图内不混用。
4. 颜色语义固定：达标=绿、预警=黄、未达标=红，全篇一致。
5. 明细数据放附录，正文只放结论图。

## 五、常见口径错误清单（汇报前自查）

- [ ] 把公共收益计入物业公司经营收入，虚增利润。
- [ ] 收缴率分母用了"在管户数"而非"应收账单金额"，导致数字偏高。
- [ ] 当期收缴率里混入了往年陈欠回收，虚高。
- [ ] 人力成本漏算社保公积金、加班费、外包折算人工。
- [ ] 能耗未区分"公共分摊"与"物业自用"。
- [ ] 一次性支出（如大修）未单独列示，导致月度可比性失真。
- [ ] 人均效能只报人数变化，不报人均产值/人均管理面积变化。
- [ ] 异常归因只写"市场原因""客观因素"，没有落到具体事件和责任人。
- [ ] 上月的行动项没有回执跟踪。
